# 多架无人机联合吊运研究

围绕含电池机体质量、载荷、持续/峰值推重比、加速度、空速与地速、风及制动空间，整理原始证据、解析计算和可复现的简化模型；补充PID之外的控制架构与共点/分布式挂点分析。

## 具体结论与实现选择

完整论证见[研究结论与实现建议](CONCLUSIONS.md)，附[逐项数值证据](CONCLUSION_EVIDENCE.json)。

| 要解决的问题 | 本研究的明确判断 |
|---|---|
| 首轮仿真用什么参数？ | 三机、每机含电池0.6 kg、载荷0.6 kg、1 m绳、20°绳角；先用1 m/s、0.5 m/s²、1 m/s³。名义两种示范实现均通过当前模型判据和细化检查。 |
| 载荷能否直接提到1.8 kg？ | 不作为名义工作点：配置总推重比降至1.087，独立编队几乎耗尽12.8 N合力上限，约6.85%采样发生指令裁剪。 |
| 速度先取多少？ | 以1 m/s为共同起点。独立编队2 m/s仅在已测名义工况通过；3 m/s时姿态峰值10.193°超过人为10°阈值，不能用推力未饱和判定合格。 |
| 3 m制动空间能否用2 m/s？ | 在净减速度0.5 m/s²、急动度1 m/s³、延迟0.1 s假设下不合适：1/2 m/s的理想停止距离分别1.35/4.70 m，还未加入实际扰动与包络余量。 |
| 单挂点还是分布式？ | 只有平移任务可考虑共点；需要独立刚体姿态控制时，选至少三个非共线分布式挂点，并核查正张力与逐机可行性。 |
| PID之外先实现什么？ | 先做完整几何控制与约束绳力/单电机分配；约束主导时接NMPC，高机动且传感/算力具备时再做全系统规划与INDI。 |

表中模型结论对应已写明的配置；12.8 N是研究假设，不是实机持续额定值。完整文件分别标明厂商/论文证据、解析结果、已执行仿真和工程建议。尚未获得真机安全认证或通用安全速度。

研究数据截至 **2026-11-01 06:00 UTC+8**。之后仅归纳已有证据、整理具体结论、核验和发布，没有增加动力学试验。

## 复核数据完整性

只需Python 3.12及标准库，在仓库根目录运行：

```bash
python tools/verify_publication.py
python tools/check_conclusions.py
```

前者核对发布清单、原始校验和、最终报告哈希、620条记录及612份时序；后者将结论表中的载荷、速度、风/时延和制动数值与原始结果逐项核对。均不积分动力学。GitHub Actions执行同样的检查。

需要读取NPZ或复算现有模型时，依赖见`night_research/requirements.txt`。已有动力学脚本是后续研究入口，不需要为了阅读报告重新启动批量实验。原始B0不是PX4或ArduPilot即插即用配置。

## 证据与限制

厂商直接证据、论文实体实验、论文仿真/理论、本轮仿真、解析计算和未验证假设分别标注。原报告24项资料与夜间18组核查材料含重叠，不能合计为42篇独立论文。第三方论文全文未在仓库重新分发；原始链接、读取范围和下载记录均保留。

当前运行模型采用刚体载荷、无人机质点、受拉弹性绳和一阶合力响应，省略无人机自身姿态、单旋翼分配、电池热/内阻、尾流和地面接触；控制器使用理想状态和精确绳力前馈。尚未完成目标实机全套辨识、完整飞控验证、全部网格或新的实飞。

本仓库尚未指定开源许可证。引用来源和第三方资料的权利归属见原始来源。
